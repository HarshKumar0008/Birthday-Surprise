# Birthday Surprise Website ❤️

1. Open `index.html` in a browser to preview the birthday surprise. The Share button becomes useful after publishing it online.
2. Open the gift, tap all three candles, release the balloons, and cut the cake to reveal the final birthday message. A cartoon Supriya in a personalized shirt reaches out to slice the cake in the decorated party scene.
3. The Happy Birthday melody is synthesized in the browser and starts when the last candle is lit. No music file is needed; use the song button to stop or replay it.
4. To personalize the page, update Supriya's name and the birthday note in `index.html`.
5. Edit the three memory cards and their `data-message` notes to add your own memories or inside jokes.
6. The site needs no image or audio files. Google Fonts is the only external resource. On GitHub Pages, the app shell also stays available offline after the first visit.
7. To publish with GitHub Pages, set the repository's **Pages → Build and deployment** source to **Deploy from a branch**, choose **main** and **/(root)**, then save. This site's address is https://harshkumar0008.github.io/Birthday-Surprise/ .
8. On her phone, she can open the link in Safari or Chrome, use **Share this surprise**, and optionally add the site to her Home Screen for app-like access.
